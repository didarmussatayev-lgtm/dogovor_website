# DOCX Template Instructions

The file `soglasie_template.docx` must be placed in this directory.
Binary DOCX files cannot be auto-generated by code, so you need to create it manually.

## How to create the template

1. Open Microsoft Word or LibreOffice Writer.
2. Create a document with the following Jinja2-style placeholders (use docxtpl syntax):

```
СОГЛАСИЕ НА ОБРАБОТКУ ПЕРСОНАЛЬНЫХ ДАННЫХ
И ПРОВЕДЕНИЕ МЕДИЦИНСКИХ ПРОЦЕДУР

Номер соглашения: {{ agreement_id }}
Дата: {{ date }}

ФИО:       {{ full_name }}
Телефон:   {{ phone }}
ИИН:       {{ iin }}

Аллергия / непереносимость:
{{ allergy }}

Я, {{ full_name }}, даю своё согласие на обработку персональных данных
и проведение медицинских процедур.

Подпись клиента:
{{ signature }}
```

3. For the signature placeholder `{{ signature }}`, it will be replaced by an inline PNG image
   (50 mm wide) via `docxtpl.InlineImage`.  In the Word document, just type `{{ signature }}`
   where you want the image to appear — docxtpl will substitute it automatically.

4. Save the file as `soglasie_template.docx` in this directory.

## Placeholders summary

| Placeholder      | Value                                |
|------------------|--------------------------------------|
| `{{ agreement_id }}` | Unique agreement ID (UUID-based) |
| `{{ date }}`     | Current date (dd.mm.yyyy)            |
| `{{ full_name }}` | Client's full name                  |
| `{{ phone }}`    | Phone number                         |
| `{{ iin }}`      | 12-digit IIN                         |
| `{{ allergy }}`  | Allergy/intolerance text             |
| `{{ signature }}` | PNG image of the client's signature |

## Fallback during development

If the template is missing, the server returns HTTP 500 with:
```json
{"detail": "Document template not found on server. Please contact support."}
```

Create a minimal template to unblock local development.
